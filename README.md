# Digikala Clone

An Android e-commerce application inspired by [Digikala](https://www.digikala.com/), one of Iran's leading online shopping platforms.

This project is built with **Kotlin** and **Jetpack Compose**, with a focus on modern Android development practices, UI implementation, and maintainable application architecture.

## Overview

The goal of this project is to explore the development of a modern Android shopping application inspired by Digikala. It serves as a practical project for learning, experimenting with Android technologies, and improving software development skills.

## Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Platform:** Android
- **Build System:** Gradle

## Getting Started

### Prerequisites

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amirhr8/Digikala.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Run the application on an Android emulator or a connected device.

## Project Goals

- Practice modern Android application development.
- Explore declarative UI development with Jetpack Compose.
- Improve code organization and maintainability.
- Build a practical e-commerce application for portfolio development.
